# 디자인 규칙

기준 시안은 "암실"이다. 어두운 바탕 위에서 사진만 밝게 보이게 하고, 화면의 나머지는 사진보다 눈에 덜 띄게 한다.

## 원칙

- 사진이 주인공이다. 강조색은 현재 선택과 저장 버튼에만 쓴다.
- 한 화면에 목록, 미리보기, 보정이 함께 보인다. 모달과 숨은 메뉴를 쓰지 않는다.
- 장식을 넣지 않는다. 그라데이션, 일러스트, 애니메이션 효과가 없다.
- 모든 문구는 [GLOSSARY.md](../GLOSSARY.md)의 용어를 쓴다.

## 색

CSS 변수로 정의하고, 화면 코드에서 색 값을 직접 쓰지 않는다. 테마는 어두운 테마 하나만 둔다.

| 변수 | 값 | 쓰는 곳 |
| --- | --- | --- |
| `--bg` | `#17181A` | 페이지 바탕 |
| `--panel` | `#1F2023` | 목록, 보정 패널, 보조 버튼 |
| `--stage` | `#0F1012` | 미리보기 뒤 무대 |
| `--line` | `#2A2C30` | 영역 경계선 |
| `--line-strong` | `#3A3C41` | 버튼, 입력 테두리 |
| `--text` | `#E8E8E6` | 본문 |
| `--muted` | `#A6A8AD` | 보조 문구, 수치, 라벨 |
| `--accent` | `#4C9EFF` | 선택 테두리, 저장 버튼, 슬라이더 |
| `--accent-text` | `#0B1220` | 강조색 위 글자 |
| `--accent-soft` | `#24303F` | 선택된 목록 항목 바탕 |
| `--accent-label` | `#9DC9FF` | 프린트 표시 |
| `--focus` | `#7DB8FF` | 키보드 포커스 테두리 |
| `--danger` | `#FF7A7A` | 불러오기·저장 실패 문구 |

- 글자와 바탕의 명암비는 본문 4.5:1, 큰 글자와 아이콘 3:1 이상을 지킨다. 새 색을 더할 때 이 기준을 확인한다.
- 사진 미리보기에는 그림자 `0 8px 32px rgba(0,0,0,0.5)`만 준다. 테두리를 두르지 않는다.

## 글꼴

웹 글꼴을 쓰지 않고 시스템 글꼴을 쓴다. 다섯 언어의 글자 모양이 각 언어에 맞아야 하기 때문이다. 한국어 웹 글꼴로 일본어와 중국어를 표시하면 한자 모양이 어긋난다.

`<html lang>`에 따라 글꼴 목록을 바꾼다.

| 언어 | 글꼴 목록 |
| --- | --- |
| 기본, `en` | `system-ui, -apple-system, "Segoe UI", sans-serif` |
| `ko` | `"Apple SD Gothic Neo", "Malgun Gothic", system-ui, sans-serif` |
| `ja` | `"Hiragino Sans", "Yu Gothic UI", "Meiryo", system-ui, sans-serif` |
| `zh-Hans` | `"PingFang SC", "Microsoft YaHei", system-ui, sans-serif` |
| `zh-Hant` | `"PingFang TC", "Microsoft JhengHei", system-ui, sans-serif` |

| 쓰임 | 크기 | 굵기 |
| --- | --- | --- |
| 앱 제목 | 16px | 700 |
| 본문, 버튼 | 14px | 400 |
| 저장 버튼 | 15px | 700 |
| 라벨, 수치 | 13px | 400 |
| 파일 이름 | 12px | 400 |
| 종류 표시, 바닥글 | 11–12px | 400 |

- 슬라이더 수치는 `font-variant-numeric: tabular-nums`로 자리 폭을 고정한다.
- 대문자 변환과 글자 사이 넓히기를 문구에 쓰지 않는다. CJK 문구에서 어색해진다.

## 간격과 모양

- 간격은 4, 8, 12, 16, 20, 24px만 쓴다.
- 모서리는 썸네일 4px, 입력과 선택 상자 6px, 버튼과 패널 8px이다.
- 영역은 바탕색 차이와 1px `--line` 경계선으로 나눈다. 카드 그림자를 쓰지 않는다.

## 배치

넓은 화면은 세 칸이다.

| 칸 | 내용 | 너비 |
| --- | --- | --- |
| 목록 | 이미지 열기 버튼, 열린 이미지 목록 | 기본 240px |
| 미리보기 | 사진, 방향 버튼 | 남은 공간 전부 |
| 보정 | 슬라이더 4개, 초기화, 저장 | 기본 260px |

- 위에는 앱 제목과 언어 선택을, 아래에는 개인 정보 안내를 둔다.
- 화면이 좁아지면 미디어 쿼리 대신 `flex-wrap`으로 목록, 미리보기, 보정 순서대로 위아래로 쌓는다.
- 휴대폰 너비에서 가로 스크롤이 생기지 않는다. 양옆 여백은 16px 이상이다.
- 미리보기는 사진 비율을 지키고 무대 안에 맞춘다. 사진을 잘라 보이지 않는다.

## 구성 요소

### 버튼

| 종류 | 모양 | 쓰는 곳 |
| --- | --- | --- |
| 주 버튼 | `--accent` 바탕, `--accent-text` 글자, 테두리 없음 | 저장 하나뿐 |
| 보조 버튼 | `--panel` 또는 투명 바탕, `--line-strong` 테두리 | 초기화 |
| 아이콘 버튼 | 보조 버튼 모양, 20px 아이콘, 글자 없음 | 왼쪽 회전, 오른쪽 회전, 좌우 반전 |
| 열기 버튼 | 투명 바탕, 점선 `--line-strong` 테두리 | 이미지 열기와 끌어다 놓기 안내 |

- 누를 수 있는 것은 모두 가로세로 44px 이상이다.
- 아이콘 버튼에는 `aria-label`과 `title`을 둔다. 문구는 i18n 사전에서 가져온다.
- 쓸 수 없는 버튼은 `disabled`로 막고 불투명도 0.4로 표시한다.

### 목록 항목

- 64×36px 썸네일 오른쪽에 파일 이름과 종류 표시를 위아래로 둔다. 긴 파일 이름은 말줄임표로 줄인다.
- 프린트는 `--accent-label`, 사진은 `--muted`로 종류를 표시한다.
- 선택된 항목은 `aria-current="true"`이고 `--accent` 테두리와 `--accent-soft` 바탕을 쓴다.

### 슬라이더

- 라벨과 현재 수치를 한 줄에, 슬라이더를 그 아래에 둔다.
- `accent-color: var(--accent)`만 지정하고 브라우저 기본 슬라이더를 쓴다.
- 0은 `0`, 양수는 `+12`, 음수는 `−8`처럼 표시한다. 음수 기호는 U+2212이다.

### 아이콘

- 24 단위 viewBox의 인라인 SVG이고, 선 굵기 2, 둥근 끝, `currentColor`를 쓴다.
- 아이콘 SVG에는 `aria-hidden="true"`를 둔다. 이름은 버튼이 가진다.

### 상태 문구

- 불러오기와 저장 실패는 `#status`(`aria-live="polite"`)에 `--danger` 색으로 표시한다.
- 성공은 따로 알리지 않는다. 내려받기가 시작되는 것으로 충분하다.

## 상호 작용

- 키보드 포커스는 `:focus-visible`에서 2px `--focus` 테두리, 2px 간격으로 표시한다. 포커스 표시를 지우지 않는다.
- 끌어다 놓는 동안 열기 버튼의 테두리를 `--accent` 실선으로 바꾼다.
- 전환 효과는 색과 테두리에만 120ms 이내로 쓴다. `prefers-reduced-motion: reduce`이면 쓰지 않는다.
- 커서는 누를 수 있는 것에만 `pointer`이다.
